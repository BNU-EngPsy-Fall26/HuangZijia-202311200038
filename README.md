# 面试员工：信号检测论交互实验

这是一个纯前端信号检测论（Signal Detection Theory, SDT）小游戏。场景设定为“面试员工”：用户扮演招聘面试官，根据候选人的简历匹配度、结构化面试回答、现场任务表现和风险信号，在限时内判断是否录用。

## 如何运行

直接双击 `index.html`，或在浏览器中打开 `index.html` 即可运行。

项目不需要安装依赖，也不需要后端服务。

## 文件结构

- `index.html`：网页结构与实验页面
- `styles.css`：页面样式与响应式布局
- `app.js`：候选人生成、交互逻辑、Canvas 绘制、SDT 结果计算
- `README.md`：运行说明

## 实验参数

- 信号 S：候选人实际为高绩效员工
- 噪音 N：候选人实际不适合岗位
- P(S)：高绩效候选人出现的先验概率，可在页面中调节
- d'：信号与噪音的可分辨程度，可在页面中调节；数值越低越难
- 每题限时：10、12、15 或 20 秒
- 总试次数：20、24、32 或 40 次

## 四种 SDT 结果

- H（Hit，命中）：高绩效候选人被录用
- M（Miss，漏报）：高绩效候选人被拒绝
- FA（False Alarm，虚报）：普通候选人被误录用
- CR（Correct Rejection，正确拒绝）：普通候选人被拒绝

## 结果计算

实验结束后页面会自动统计：

- H / M / FA / CR
- P(Hit)
- P(FA)
- d'
- c
- 准确率

为避免 P(Hit) 或 P(FA) 等于 0 或 1 时 z 分数无穷大，d' 和 c 的计算使用 0.5 校正：

```text
P(Hit) = (H + 0.5) / (H + M + 1)
P(FA) = (FA + 0.5) / (FA + CR + 1)
d' = z(P(Hit)) - z(P(FA))
c = -0.5 * [z(P(Hit)) + z(P(FA))]
```

## 操作方式

- 在指导语与参数设置页阅读规则、调节参数
- 通过概念可视化调节 d'，观察信号/噪音分布距离和 ROC 曲线的变化
- 拖动判断标准 c 滑块，观察 P(Hit) 与 P(FA) 如何同时改变
- 点击“开始正式任务”生成候选人
- 点击“不录用”或“录用”做出判断
- 键盘快捷键：`A` = 不录用，`L` = 录用
- 每次判断后会显示该试次属于 H、M、FA 或 CR
- 实验结束后可点击“导出 CSV”保存逐试次记录
- 实验结束后会自动保存本机浏览器历史记录，用于多局数据对比和排行榜展示
- 结果页可点击“再次开始”直接用当前参数进行下一局练习，也可点击“调整参数”回到设置页
