## 方法与样本流程

原始记录按会话×任务去重，测试与正式补传不重复计数；同编号不同人仅依据研究者明确确认拆分。冻结候选15人，搜索候选15份（1份未完成），驾驶候选14份（1份未完成）。调整口径保留搜索14、驾驶13。总体准确率≥70%，失焦/过快/中断去重占比≤20%；搜索有效RT≥200ms、驾驶≥150ms。准确率排除失焦/中断，保留超时及过快错误；有效RT另排除错误与超时。

95%区间使用被试bootstrap百分位法，10,000次，numpy默认生成器种子20261107；配对效应整人重采样。双侧精确符号翻转穷举所有符号（包含观察组合，不加蒙特卡洛+1修正），要求零假设下差值符号可交换/对称。每种口径的两个主要p值分别进行Holm控制；区间本身未多重校正。小样本、离散p值、非正态差异和事后选择均限制结论。

有效正确RT试次数：搜索 2129，驾驶 1493。四组人数（1/2/3/4）：搜索 {'1': 5, '2': 3, '3': 2, '4': 4}；驾驶 {'1': 4, '2': 3, '3': 2, '4': 4}。1/3组搜索先做，2/4组驾驶先做，组别不完全平衡。

已有完整会话时间戳的10人耗时中位11.30分钟（范围9.28–12.72），非全样本耗时估计。旧P01驾驶90次被研究者确认为15分钟限时退出；不得据此把所有缺失归因于限时。练习过程对仅CSV记录无法独立重审，依赖程序门槛；备份中练习可核查。

## 原文对照

Posner、Snyder、Davidson（1980）实验2表1（p.166）的位置边际均值：预期249、中性266、非预期297ms；由表相减收益17、代价31ms。本项目持续收益46.87、代价11.01ms；短暂收益18.37、代价14.49ms。只对照效应方向；原文80%有效的单键信号检测，与本项目2/3有效、16项形状辨别、双键反应不同，不作毫秒大小优劣检验。来源：https://psych.hanover.edu/classes/Cognition/Papers/posner%201980.pdf

Eriksen与Eriksen（1974）出版社摘要：以H/K、S/C集合和左右杠杆反应，操纵侧翼兼容性与间距；不兼容侧翼增加RT，间距增加时RT下降。本项目中性提醒干扰58.56ms，方向相符，但箭头、中文预警、固定像素间距均不同。可公开核对摘要未给本项目可直接使用的条件均值，因此不填造原文数值。来源：https://link.springer.com/article/10.3758/BF03203267

Ghinescu等（2016）研究预期兼容性线索与线索竞争，可为准备策略提供依据；其学习任务并非本项目中文显式预警的验证。本项目预警相对普通提醒干扰降低0.40ms，区间跨零。来源：https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0167119

视觉搜索未操纵集大小，不能报告搜索斜率或宣称完整FIT复现。预警可能允许利用侧翼推断中央反应，不能将效应独占归因于注意抑制。
