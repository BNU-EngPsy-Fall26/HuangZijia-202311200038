# 太空救援：提示的帮助与代价——研究设计、结果与反思

分析冻结：2026-11-08。数据为已核验原始 CSV、9份新增备份与1份经研究者确认独立身份的平台完整Flanker记录，不是实时后台全量。本文是对已收集数据的分析；调整后口径为探索性修订，不能称为完全预注册分析。

## 研究背景：提示为什么可能既有帮助，也有代价？

在导航、监控和信息检索界面中，设计者常用位置标记和文字提醒帮助使用者发现目标。本项目关注的工程问题是：界面给出提示之后，使用者是否更容易完成任务；如果提示指错位置，或者只是重复已有要求，是否仍有帮助？因此，评价提示不能只比较“有没有提示”，还需要考察提示的可靠性、保留方式与信息内容，并同时观察速度和准确率。本文以反应时（reaction time，RT）衡量作答速度；“收益”指相对基线更快，“代价”指相对基线更慢，“干扰”指不一致与一致条件的RT差。

空间注意定向研究为第一个问题提供了依据。Posner、Snyder与Davidson（1980）通过有效、中性及无效线索区分注意定向的收益与代价。由此，本项目把“错误提示是否妨碍寻找目标”作为与“正确提示是否帮助搜索”同等重要的问题，而不是只呈现正确提示来证明界面有效。这里借用的是收益—代价的分析框架，具体任务改成了需要在16个图形中寻找红色目标并判断形状的视觉搜索；它不是原单键检测任务的逐项复制。[Posner等原文](https://psych.hanover.edu/classes/Cognition/Papers/posner%201980.pdf)

Flanker研究则提供了另一个角度：目标位置已知时，无关刺激仍可能引起反应冲突。Eriksen与Eriksen（1974）发现，不兼容侧翼比兼容侧翼造成更大的反应时损害。这意味着界面上“看哪里”的提醒与“接下来会遇到什么”的信息可能发挥不同作用。预期线索研究为提前准备策略提供了理论背景，但并不保证任意文字预警都有效。[Eriksen与Eriksen原文](https://doi.org/10.3758/BF03203267)；[Ghinescu等（2016）](https://doi.org/10.1371/journal.pone.0167119)

基于上述思路，本项目选择空间提示引导的视觉搜索与箭头Flanker两项任务，分别考察空间选择和反应冲突。共同主题是“提示的帮助与代价”，但两项任务检验不同问题，不能把其中一个任务的结果当作另一个任务的机制证据。本研究的贡献定位是对经典范式进行有理论依据、可直接检验的课程设计改编，不主张提出新的注意理论或已经验证实际驾驶应用效果。

## 研究问题与改进方式

### 实验一：撤去错误标记，能否降低误导代价？

第一项改进不是提高提示准确率，而是改变提示在目标出现后是否继续保留。持续提示可能在指错位置时继续吸引注意；短暂提示则先提供区域信息，再在搜索阵列出现时撤去。由此提出的设计设想是：保留初始引导的机会，同时减少错误标记在搜索过程中的持续影响。这是待检验的预测，而不是原文已经证明的结论；撤去提示也可能增加记忆负担，或者无法消除已经发生的注意定向。

两种提示在阵列出现前均显示300 ms，有效率均为2/3，提示位置不预测圆形／三角形或正确按键。持续条件在阵列出现后保留边框，短暂条件恢复细灰框；目标、干扰物、项目数和作答方式不变。这样可以避免将“提示更可靠”“目标更容易”与“提示是否保留”的作用混为一谈。两种形式在区块内混合出现，固定配额后随机排列。

任务包含无提示、持续有效、持续无效、短暂有效、短暂无效五种条件，分别安排40、40、20、40、20次，共160次；每条件的两种目标形状平衡。无提示条件提供共同基线，用于分别计算有效提示收益和无效提示代价。无效条件不能省略，否则无法回答本研究关于误导代价的问题。

预先定义的主要检验S-H1为“持续无效RT−短暂无效RT”，正值支持短暂提示降低代价。进一步用S-H2检查两种形式的“无效−有效”差是否不同，以区分针对误导的改善与所有条件一起加快。有效提示是否仍有收益作为次要问题；即使短暂和持续条件差异不显著，也不能据此宣称短暂提示完全保留了持续提示的收益。

### 实验二：有用的预警，是否优于一般提醒？

第二项改进聚焦提示的信息内容。普通提醒“看中央船”重复当前任务要求，信息预警“编队同向／编队反向”则准确告知下一阵列的一致性。设计设想是，知道是否会出现冲突可能帮助参与者提前准备，从而减小不一致侧翼的干扰。原有中性提示“准备驾驶”作为背景条件，既能检查经典干扰，也能区分一般提醒与具体信息预警。

三类提示均为四个汉字，在相同位置、字号和颜色下显示600 ms；其后呈现5个箭头，参与者用F／J判断中央箭头方向。提示单独不预测正确按键，左右方向与一致性分别平衡。如此控制提示时长与基本视觉格式，避免把额外准备时间误当作信息内容的作用。不过，文字语义仍不同，而且已知一致性后可能利用侧翼推断中央方向，因此不能把任何改善独占地解释为注意抑制增强。

该任务采用3类提示×2种一致性的被试内设计，每组合20次，左右目标各10次，共120次。主要检验F-H2为“普通提醒下的干扰−信息预警下的干扰”，其中干扰定义为不一致RT减一致RT。直接比较差值，而不只比较两类提示的总体RT，是因为一致与不一致条件同时等量加快只能说明整体准备收益，不能证明冲突减小。

## 设计取舍与实施过程

### 为什么使用被试内设计并同时报告准确率？

每位参与者完成其所在任务的全部条件，使主要比较发生在同一个人内部，以减少不同人的基础反应速度对比较的影响。条件配额固定后随机排序，搜索形状与Flanker方向在条件内平衡，统计时先按目标身份等权汇总，再按参与者等权汇总。四组编号规则交替任务顺序，并平衡搜索按键映射；实际保留人数并不完全平衡，因此报告组数，而不将顺序影响视为已排除。

反应时只统计符合规则的正确反应，同时报告准确率和超时率。若某种提示让人更快却更容易出错，就不能简单称为更好的界面。原设计每细分条件至少安排10次；错误、失焦等排除后的有效正确RT下限属于分析规则，与设计配额分别披露。所有事后例外及恢复原规则的敏感性分析见后文。

### 为什么加入太空救援主题，却限制游戏元素？

开发过程中，研究者提出简化任务，并在真人预试后反馈体验单调，项目据此简化搜索操作、加强指导语，并用“物资搜救”和“编队驾驶”组织两项任务。主题用于帮助理解操作和提供进度感；飞船配色只改变刺激区外观，正式试次不加入速度奖励、随机奖励、扣命或动态背景，以减少游戏激励改变速度—准确率策略的风险。游戏化没有独立对照实验，因此不能声称它已提高兴趣、完成率或测量质量。

练习、正式开始和休息后均使用居中提示，按空格后倒计时3秒，再进入注视点与试次。研究者随后因退出和阅读需求取消整场15分钟自动停止，保留单题作答时限；本报告的冻结样本仍来自旧政策，不能将新界面政策解释为这批数据的原因。个人报告及模型在参与结束后呈现，避免提前透露具体预测；模型是教学近似，不是对原论文模型的精确复现或对个人数据的拟合。

### 设计理由、原预测与结果后的反思如何区分？

本节根据现有设计文档、程序与开发记录整理设计逻辑，其中的S-H1和F-H2可追溯到早期公开提交；本节文字是在结果已知后补写，不能视为收数前注册文件。预试后的界面修订、模式例外、筛选门槛调整和取消总限时分别保留记录。结果后的可能机制集中放在讨论中，不回写为已经预先验证的设计理由。

因此，本研究呈现的是一条可以核查的过程：从工程问题形成具体假设，为每个假设设置可区分解释的条件，控制可以控制的因素，再用实际效应及敏感性分析评价改进。即使未观察到明确优势，也应保留原预测，并说明哪些设计假设仍需独立实验检验。

## 方法与样本流程

原始记录按会话×任务去重，测试与正式补传不重复计数；同编号不同人仅依据研究者明确确认拆分。冻结候选16人，搜索候选15份（1份未完成），驾驶候选15份（1份未完成）。调整口径保留搜索14、驾驶14。总体准确率≥70%，失焦/过快/中断去重占比≤20%；搜索有效RT≥200ms、驾驶≥150ms。准确率排除失焦/中断，保留超时及过快错误；有效RT另排除错误与超时。

95%区间使用被试bootstrap百分位法，10,000次，numpy默认生成器种子20261107；配对效应整人重采样。双侧精确符号翻转穷举所有符号（包含观察组合，不加蒙特卡洛+1修正），要求零假设下差值符号可交换/对称。每种口径的两个主要p值分别进行Holm控制；区间本身未多重校正。小样本、离散p值、非正态差异和事后选择均限制结论。

有效正确RT试次数：搜索 2129，驾驶 1608。四组人数（1/2/3/4）：搜索 {'1': 5, '2': 3, '3': 2, '4': 4}；驾驶 {'1': 4, '2': 4, '3': 2, '4': 4}。1/3组搜索先做，2/4组驾驶先做，组别不完全平衡。

已有完整会话时间戳的10人耗时中位11.30分钟（范围9.28–12.72），非全样本耗时估计。旧P01驾驶90次被研究者确认为15分钟限时退出；不得据此把所有缺失归因于限时。练习过程对仅CSV记录无法独立重审，依赖程序门槛；备份中练习可核查。

## 两项改进未获支持：结果、解释与边界

以下数字固定为调整口径；严格原规则结果见敏感性表。搜索无效−有效差为45.37ms，95%CI [12.91,80.46]；中性Flanker干扰为57.65ms，[47.28,69.19]。这些未校正描述性区间支持经典方向，但不能代替主要改进检验，也不能证明所有注意机制均测量充分。

**短暂提示。** 预先定义收益为持续无效−短暂无效RT，估计−3.48ms，95%CI [−41.61,32.06]，双侧p=.8652，Holm p=1.000。点估计未呈现预期优势，区间容纳收益与损害，不能认定等效。待检验解释：两类提示都先出现300ms，阵列开始时注意可能已被定向，撤去边框未必解除此前影响；撤去提示也可能减少可利用的外部信息。没有眼动或重新定向测量，不能选择其中一种解释作为已证实机制。

**信息预警。** 收益为普通提醒干扰−信息预警干扰，估计1.23ms，95%CI [−6.04,8.75]，双侧p=.7543，Holm p=1.000。普通提醒已要求看中央目标，预警的额外信息可能收益有限；准确的一致性预告还可能允许利用侧翼推断反应，改变策略而非单纯增强抑制。这些均为结果后的机制假设。未做提示理解／利用的独立操纵检查，不能断言参与者确实利用或忽略了预警。

**准确率与稳健性。** 对应主要错误率差为−0.36和2.50个百分点，区间均跨零，不能证明不存在速度—准确率权衡。四种筛选口径结论一致，意味着恢复规则没有改变本次结论，并不消除小样本、事后调整、顺序不平衡、设备差异及限时退出选择偏差。不能仅把不显著归因于样本量不足；样本量影响估计精度，但尚无证据确认真实改进收益。

**工程意义与下一步。** 现有证据不足以推荐用短暂提示替代持续提示，或以信息预警替代普通提醒；也没有证明它们完全无效。未事先设定等效界值，不能事后凭不显著宣称等效。后续独立研究应先确定实际有意义的最小收益并规划样本量，增加提示理解检查、操纵提示时长或撤除时点，并预先固定筛选规则。不要为了获得显著结果继续抽样、删人或更换主指标；模型滑块是教学模拟，不是当前数据的机制拟合。
