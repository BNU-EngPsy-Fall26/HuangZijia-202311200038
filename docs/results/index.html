选择分析口径

每人先取“条件 × 目标身份”的正确 RT 中位数，再对两种身份等权平均；最后对参与者等权汇总。单位 ms。准确率、超时率也先按身份、再按人等权，不将试次当独立被试。

两个主要改进检验

线段是 95% 被试 bootstrap 百分位区间（10,000 次，种子 20261107），不是多重比较校正区间。双侧精确符号翻转检验穷举 2ⁿ 个符号组合，要求零假设下配对差具有符号对称性；两项主要检验在各口径内用 Holm 校正。四种口径是敏感性分析，不是四次独立发现。

条件结果：速度与准确率一起看

准确率分母排除失焦／中断，包含错误、超时与过快反应；RT 另排除错误、超时，以及搜索 <200 ms / Flanker <150 ms。0% 超时是当前样本的观察结果，不意味着该风险不存在。

经典方向与机制检查

本节区间为描述性、未做多重比较校正。S-H2 是提示有效性差值的交互检查；不能因为某一个条件显著、另一个不显著而宣称两者不同。

调整会改变结论吗？

四种口径中，两项主要改进的区间均跨过零，Holm 校正 p 均为 1.000。当前证据不足以支持短暂提示降低误导代价、或信息预警优于普通提醒；也不足以建立等效或证明完全无效。

样本流程与质量

冻结输入包含14个不同参与者身份：13人完成搜索，12人完成Flanker；1人的Flanker只有90次，另1人只有1次搜索。重复上传按会话与任务去重，误用相同编号的不同参与者依据研究者确认分开。正式与补传记录不重复计数。四名原测试模式记录经过研究者事后批准纳入，不等于原始采集时为正式模式。

已持有完整会话时间戳的9人，用时中位数11.25分钟，范围9.28–12.72分钟；其余人缺少可用的完整会话起止，不能据试次时间反推全程。未完成的90次Flanker已由研究者确认为15分钟限时退出，但不能凭这一个案例认定所有缺失都由限时造成。

本冻结样本均无新 timing_policy 标记，来自旧版15分钟政策；取消总限时发生于这批记录之后。本分析不检验时间政策效果，不把后来更正上传的时间当作实际实验时间。四组分配不完全平衡，详见当前口径组数；本研究不具备精确区分练习、顺序与设备效应的样本量。

与原文对照：什么一致，什么还不能说？

原研究与可核对结果本项目结果及边界
Posner、Snyder 与 Davidson（1980），实验2，p.166 表1：位置提示的边际平均 RT 为预期249、中性266、非预期297 ms，表内相减得到收益17、代价31 ms。该实验是单键检测，位置提示80%有效。调整口径持续提示收益44.0、代价17.1 ms；短暂收益20.6、代价14.8 ms。有效−无效方向与注意定向框架相容，但代价区间跨零。我们的16项形状辨别、2/3有效率、双键反应及无眼动监测均不同，不比较绝对快慢或宣称复制了原文效应大小。
Eriksen 与 Eriksen（1974），出版社摘要：H/K与S/C字母集合、左右杠杆、1秒显示；反应不兼容侧翼比兼容侧翼产生更大RT损害，间距增大时RT下降。中性文字下干扰57.9 ms，方向与经典兼容性效应一致。我们使用箭头、固定像素间距、F/J键与600ms文字提示，不是原任务逐项复现。公开可核对摘要没有可直接配对的组均值，因此不编造原文毫秒值。
Ghinescu 等（2016），摘要与实验结果：考察预测兼容性线索的学习和线索竞争，显示策略可随预期与线索学习变化。为提前准备假设提供背景，不直接验证本项目的中文明确预警。这里预警相对普通提醒的干扰减少仅0.7 ms；侧翼反推答案、语义和策略改变都仍可能影响结果。

本项目无搜索集大小变化，不能估计经典搜索斜率，也不把形状辨别任务称为完整 FIT 复现。原文比较是有边界的理论与方法对照，不是跨研究优劣检验。上表本项目数字固定为调整口径；切换分析口径时请以上方实时结果为准。
