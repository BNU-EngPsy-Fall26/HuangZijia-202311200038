经典效应出现，
改进优势尚不明确。

2026-11-08 已核验样本冻结分析（已加入新核验的完整会话）。这里是研究汇总，不是刚完成实验的个人报告，也不是模型模拟。新的后台上传不会自动加入。最新核对新增一名经研究者确认的完整Flanker；另有一份30次未完成记录未纳入。

调整口径包括四名误选测试模式的参与者，并将 Flanker 细分条件下限从 6 次降至 5 次；两项改进均未得到明确支持。下方可切换到原规则，检查结论是否依赖调整。小样本与事后更改限制推断强度。

选择分析口径

每人先取“条件 × 目标身份”的正确 RT 中位数，再对两种身份等权平均；最后对参与者等权汇总。单位 ms。准确率、超时率也先按身份、再按人等权，不将试次当独立被试。

两个主要改进检验

线段是 95% 被试 bootstrap 百分位区间（10,000 次，种子 20261107），不是多重比较校正区间。双侧精确符号翻转检验穷举 2ⁿ 个符号组合，要求零假设下配对差具有符号对称性；两项主要检验在各口径内用 Holm 校正。四种口径是敏感性分析，不是四次独立发现。

条件结果：速度与准确率一起看

准确率分母排除失焦／中断，包含错误、超时与过快反应；RT 另排除错误、超时，以及搜索 <200 ms / Flanker <150 ms。0% 超时是当前样本的观察结果，不意味着该风险不存在。

经典方向与机制检查

本节区间为描述性、未做多重比较校正。S-H2 是提示有效性差值的交互检查；不能因为某一个条件显著、另一个不显著而宣称两者不同。

调整会改变结论吗？

四种口径中，两项主要改进的区间均跨过零，Holm 校正 p 均为 1.000。当前证据不足以支持短暂提示降低误导代价、或信息预警优于普通提醒；也不足以建立等效或证明完全无效。

如何理解两项改进不显著？

以下数字固定为调整口径；严格原规则结果见敏感性表。搜索无效−有效差为45.37ms，95%CI [12.91,80.46]；中性Flanker干扰为57.65ms，[47.28,69.19]。这些未校正描述性区间支持经典方向，但不能代替主要改进检验，也不能证明所有注意机制均测量充分。

短暂提示。 预先定义收益为持续无效−短暂无效RT，估计−3.48ms，95%CI [−41.61,32.06]，双侧p=.8652，Holm p=1.000。点估计未呈现预期优势，区间容纳收益与损害，不能认定等效。待检验解释：两类提示都先出现300ms，阵列开始时注意可能已被定向，撤去边框未必解除此前影响；撤去提示也可能减少可利用的外部信息。没有眼动或重新定向测量，不能选择其中一种解释作为已证实机制。

信息预警。 收益为普通提醒干扰−信息预警干扰，估计1.23ms，95%CI [−6.04,8.75]，双侧p=.7543，Holm p=1.000。普通提醒已要求看中央目标，预警的额外信息可能收益有限；准确的一致性预告还可能允许利用侧翼推断反应，改变策略而非单纯增强抑制。这些均为结果后的机制假设。未做提示理解／利用的独立操纵检查，不能断言参与者确实利用或忽略了预警。

准确率与稳健性。 对应主要错误率差为−0.36和2.50个百分点，区间均跨零，不能证明不存在速度—准确率权衡。四种筛选口径结论一致，意味着恢复规则没有改变本次结论，并不消除小样本、事后调整、顺序不平衡、设备差异及限时退出选择偏差。不能仅把不显著归因于样本量不足；样本量影响估计精度，但尚无证据确认真实改进收益。

工程意义与下一步。 现有证据不足以推荐用短暂提示替代持续提示，或以信息预警替代普通提醒；也没有证明它们完全无效。未事先设定等效界值，不能事后凭不显著宣称等效。后续独立研究应先确定实际有意义的最小收益并规划样本量，增加提示理解检查、操纵提示时长或撤除时点，并预先固定筛选规则。不要为了获得显著结果继续抽样、删人或更换主指标；模型滑块是教学模拟，不是当前数据的机制拟合。

样本流程与质量

冻结输入包含16个不同参与者身份：14人完成搜索，14人完成Flanker；1人的Flanker只有90次，另1人只有1次搜索。重复上传按会话与任务去重，误用相同编号的不同参与者依据研究者确认分开。正式与补传记录不重复计数。四名原测试模式记录经过研究者事后批准纳入，不等于原始采集时为正式模式。新增完整Flanker仅有该任务记录；完成性依据120次及未完成标记均为false，公开接口无练习记录，练习未独立重审。

已持有完整会话时间戳的10人，用时中位数11.30分钟，范围9.28–12.72分钟；其余人缺少可用的完整会话起止，不能据试次时间反推全程。未完成的90次Flanker已由研究者确认为15分钟限时退出，但不能凭这一个案例认定所有缺失都由限时造成。

本冻结样本均无新 timing_policy 标记，来自旧版15分钟政策；取消总限时发生于这批记录之后。本分析不检验时间政策效果，不把后来更正上传的时间当作实际实验时间。四组分配不完全平衡，详见当前口径组数；本研究不具备精确区分练习、顺序与设备效应的样本量。

与原文对照：什么一致，什么还不能说？

原研究与可核对结果本项目结果及边界
Posner、Snyder 与 Davidson（1980），实验2，p.166 表1：位置提示的边际平均 RT 为预期249、中性266、非预期297 ms，表内相减得到收益17、代价31 ms。该实验是单键检测，位置提示80%有效。调整口径持续提示收益46.9、代价11.0 ms；短暂收益18.4、代价14.5 ms。有效−无效方向与注意定向框架相容，但代价区间跨零。我们的16项形状辨别、2/3有效率、双键反应及无眼动监测均不同，不比较绝对快慢或宣称复制了原文效应大小。
Eriksen 与 Eriksen（1974），全文p.145–147、图1与表3：6名被试，5类噪声×3档间距；H/K与S/C、左右杠杆、1秒显示、错误重跑。间距F(2,10)=58.28，噪声F(4,20)=28.23，均p<.0001；交互F(8,40)=16.08。不兼容条件最慢。最小间距不兼容错误率21.5%，相同字母4%。本项目中性提醒干扰57.65ms，[47.28,69.19]；一致／不一致准确率98.93%／93.57%。箭头、固定像素间距、600ms中文提示及不补做错误均不同，只对照方向。原研究总体ANOVA不等于本项目成对检验，不从图中编造精确均值。完整方法及试次数对照见报告。
Ghinescu 等（2016），摘要与实验结果：考察预测兼容性线索的学习和线索竞争，显示策略可随预期与线索学习变化。为提前准备假设提供背景，不直接验证本项目的中文明确预警。这里预警相对普通提醒的干扰减少仅1.2 ms；侧翼反推答案、语义和策略改变都仍可能影响结果。

本项目无搜索集大小变化，不能估计经典搜索斜率，也不把形状辨别任务称为完整 FIT 复现。原文比较是有边界的理论与方法对照，不是跨研究优劣检验。上表本项目数字固定为调整口径；切换分析口径时请以上方实时结果为准。
